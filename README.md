# AEI FireGuard Systems - Corporate Website & Admin Portal

This is the official B2B corporate website and admin dashboard for **Associated Engg. Industries (AFPS Division)**. The application showcases DGMS-approved Automatic Fire Detection and Suppression Systems designed for heavy earth-moving machinery in the mining and construction sectors.

## 🚀 Features

- **Modern & Responsive UI**: Built with React, Tailwind CSS, and shadcn/ui for a premium, highly responsive user experience across desktop and mobile.
- **Interactive 3D Globe**: Custom interactive 3D globe visualization (using Three.js and React Three Fiber) highlighting the company's global presence and major international markets.
- **Dynamic Content Management**: A secure, integrated Admin Dashboard allowing administrators to manage "Products" and "Projects" dynamically.
- **Supabase Backend**: Utilizes Supabase (PostgreSQL) for a scalable database, row-level security (RLS), media storage, and authentication.
- **Form Integration**: Contact and enquiry forms seamlessly integrated with WhatsApp and Email functionalities for rapid B2B communication.
- **Advanced Animations**: Smooth page transitions, scroll-linked animations, and glowing UI effects to create a state-of-the-art corporate web presence.

## 🛠️ Technology Stack

- **Frontend**: React (Vite), TypeScript, Tailwind CSS
- **UI Components**: shadcn/ui, Radix UI, Lucide Icons, Framer Motion
- **3D Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Backend/Database**: Supabase (PostgreSQL, Auth, Storage)
- **Routing**: React Router DOM
- **State Management & Fetching**: React Query, Supabase Client
